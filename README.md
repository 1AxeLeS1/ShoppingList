# Приложение "Список покупок"

Мобильное Android-приложение для ведения списка покупок, разработанное в рамках лабораторной работы. 

## Стек технологий
*   **Язык:** Kotlin
*   **UI:** Jetpack Compose (Material 3)
*   **Архитектура:** MVVM (Model-View-ViewModel)
*   **Локальная БД:** Room (SQLite)
*   **Настройки:** DataStore Preferences
*   **Навигация:** Navigation Compose
*   **Асинхронность:** Coroutines / Flow

##  Основной функционал
*   **Управление списком:** Добавление, редактирование (через чекбоксы) и удаление товаров.
*   **Категории и цены:** Возможность указывать категорию и стоимость товара.
*   **Подсчет суммы:** Кликабельный счетчик, переключающий режимы: *Общая сумма*, *Осталось купить*, *В корзине*.
*   **Сортировка:** По категориям, по алфавиту (с поддержкой кириллицы) и по цене (возрастание/убывание).
*   **История покупок:** Удаленные товары не стираются сразу, а отправляются в Архив (историю), откуда их можно восстановить или удалить навсегда.
*   **Массовые действия:** Возможность разом отправить в архив все выполненные пункты.
*   **Шаринг:** Экспорт списка в текстовом формате через системное меню «Поделиться».
*   **Настройки:** Выбор темы (светлая/темная/системная) и валюты (₽, $, €).
*   **Авторизация:** Локальный экран входа/регистрации (с сохранением сессии).

## Как запустить проект
1. Клонируйте репозиторий: `git clone https://github.com/ВАШ_ЛОГИН/ShoppingList.git`
2. Откройте проект в **Android Studio**.
3. Дождитесь синхронизации Gradle.
4. Запустите на эмуляторе (API 26+) или физическом устройстве.
*Готовый APK файл прикреплен в разделе Releases.*
